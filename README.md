# RodoSystem

Sistema de gestão de passagens rodoviárias desenvolvido como projeto acadêmico.

## Tecnologias utilizadas

- Google Apps Script
- JavaScript
- HTML
- CSS
- Google Sheets

## Funcionalidades

- Cadastro e venda de passagens
- Controle de assentos
- Validação de dados do passageiro
- Formas de pagamento
- Listagem de passagens vendidas
- Cálculo de faturamento
- Integração com Google Sheets

## Objetivo

Projeto desenvolvido para aplicar conceitos de programação,
desenvolvimento web e manipulação de dados.
